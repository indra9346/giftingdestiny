Gifting Destiny — PHP hosting package

This package includes index.php as the PHP hosting entry point. It serves the built frontend in index.html. The interactive storefront itself remains the existing JavaScript application; this package does not add a PHP backend or database.

Install
1. Extract this folder.
2. Upload all files and folders together into the hosting web root (for example, public_html). Keep index.php, index.html, assets/, and both MP4 files at the same level.
3. Visit the domain using a PHP-enabled web host. Hash-based product routes work from the site root without extra rewrite rules.
4. Do not replace an existing WordPress index.php in-place. Ask the senior developer to integrate this package with the existing site or deploy it to a separate directory/domain.
