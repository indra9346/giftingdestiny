Gifting Destiny - PHP Hosting Deployment Package

This package contains the complete compiled Gifting Destiny luxury storefront ready for deployment to any Apache/Nginx PHP-enabled hosting environment (cPanel, Plesk, shared hosting, VPS, etc.).

Overview:
- Entry point: index.php (safely serves index.html and headers)
- Video Asset: gifting-destiny-brand-film.mp4 (Full HD 1080p, H.264/yuv420p web streaming +faststart)
- Frontend: Single-page application compiled from Vite with full responsiveness for Mobile UI and Laptop/Desktop UI.
- Direct WhatsApp checkout, dynamic product catalog, customizer preview studio, and corporate inquiry workflows.

Directory Contents:
- index.php: Main PHP entry point.
- index.html: Compiled HTML structure.
- assets/: Production JS (index-BomesXUC.js) & CSS (index-C6JlFExo.css) bundles.
- gifting-destiny-brand-film.mp4: Realistic luxury atelier background video.
- .htaccess: Web server caching, compression, and routing fallback.
- icons.svg & favicon.svg: Vector brand icon assets.

Deployment Instructions:
1. Extract the ZIP package.
2. Upload all files into the designated web root directory (e.g. public_html or a subfolder like /store).
3. Ensure index.php and index.html remain in the same directory as assets/ and the .mp4 files.
4. If integrating into an existing WordPress site, deploy into a dedicated directory (such as /shop or /storefront) so it does not conflict with WordPress's root index.php.
