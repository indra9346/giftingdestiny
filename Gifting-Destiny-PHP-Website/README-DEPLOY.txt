Gifting Destiny website — static HTML production package

Deployment
1. Extract this ZIP.
2. Upload index.html and the assets folder to the hosting web root (for example, public_html), keeping the folder structure intact.
3. Keep both MP4 files alongside index.html. The home page uses gifting-destiny-extended-v2.mp4. bgv.mp4 is retained as the previous background video.
4. Open the domain in a browser and check the home page, product pages, and images.

This is a production build of the Vite website. It is static HTML, CSS, JavaScript, and media; it does not require PHP. A PHP hosting account can serve these files. Any PHP-specific integration must be added separately.
